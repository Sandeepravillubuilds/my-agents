# My Agents

A backup of my custom agent instructions, specialized roles, and skills.

## Download

Download [my-agents-public.zip](my-agents-public.zip) and extract it. The archive preserves the original folder structure and includes all 33 approved files:

- 13 `AGENTS.md` instruction files
- 17 specialized agent role files
- 1 custom skill, `career-restart-helper`, with its `agents/openai.yaml` metadata
- A README explaining reuse and scope

Open the relevant extracted folder in Codex to use its instructions. The custom skill is under `codex-career-restart-training/.agents/skills/career-restart-helper/`.

## Scope

This is a definitions-only snapshot. Supporting knowledge bases, templates, configurations, scripts, applications, inputs, and generated outputs are not included. Some original instructions reference those local resources and absolute paths; restore the resources separately or adapt paths when reusing an agent.

The archive does not automatically sync future edits.
