# Career Restart Helper

Create review-ready drafts that the job seeker can defend in an interview.

## Required inputs

- the source resume or verified career-history file
- the target job description

If either is missing, request it. If sources conflict on a material fact, identify the conflict and pause that part of the work rather than choosing a version.

## Workflow

1. Extract the role's major responsibilities, required capabilities, preferred capabilities, and important wording.
2. Map each requirement to exact evidence in the source resume. Label it **strong**, **partial**, or **gap**.
3. Draft a positioning brief with the three most defensible themes, material gaps, and candidate questions.
4. Tailor the resume only from verified evidence. Improve relevance and clarity without changing the truth or implied seniority.
5. Create interview-preparation prompts using real examples from the source. Use questions or placeholders when a STAR detail is missing.
6. Audit every employer, title, date, qualification, tool, achievement, and metric in the result against the source.

## Default outputs

Create or return:

- an evidence map
- a short positioning brief
- a tailored resume draft
- an interview-preparation sheet
- a factual QA note with unresolved questions

Adapt filenames or presentation format to the user's project, but preserve the visible evidence and QA stages.

## Boundaries

- Never invent or silently strengthen facts, dates, metrics, employers, titles, qualifications, tools, or responsibilities.
- Keep genuine gaps visible. Offer an honest framing or learning plan when useful.
- Do not include sensitive personal information unless the user supplied it for this exact output and it is appropriate.
- Treat all materials as drafts. Never submit an application, send a message, contact a recruiter, or publish content without a separate explicit user request and review.
- Do not promise interviews, employment, income, or applicant-tracking-system outcomes.

## Quality bar

The result is complete only when every material claim is traceable to the supplied evidence, the most relevant evidence is easy to scan, gaps are not hidden, and unresolved questions are clearly listed for human review.
